# playlist-manager
The Playlist Manager application scans a directory of audio files and provides the ability to create playlist files in the "*.m3u" format.

Various devices, such as portable MP3 players and auto entertainment systems, support the M3U format for playlist files.   

This application will scan the tree of audio files and allow to user to create or add to a playlist file based on the artist name, the genre, the album name, or the source folder (usually an artist name, but not necessarily).  All of the category options depend on metadata properties existing in the audio file.

Two other tools are available: to show the content of the audio file, categorized by the selection options, and to list the files in each playlist and any files not currently in a playlist.
